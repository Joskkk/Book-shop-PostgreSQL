# Book-shop-PostgreSQL
Небольшой учебный проект базы данных книжного магазина на PostgreSQL. Проект используется для практики SQL, PostgreSQL и Bash, а также для работы с базовыми DBA-задачами.

## О проекте

В базе хранятся данные о книгах, магазинах, остатках и продажах.

## В проекте есть:

- **books** — информация о книгах;
- **stores** — магазины;
- **inventory** — количество книг в каждом магазине;
- **sales** — данные о продажах.

Между таблицами настроены первичные и внешние ключи, а также ограничения для проверки данных.

## Структура проекта
```text
book-shop-postgresql/  
├── bash/                  # Bash-скрипты  
├── sql/                   # SQL-запросы  
├── screenshots/           # Скриншоты проекта  
├── book_shop_schema.sql   # Структура БД и данные  
└── README.md
```
## Основная цель проекта - получить практический опыт работы с PostgreSQL и Linux и собрать примеры своих SQL- и Bash-скриптов в одном месте.
